# love-u-supri

Valentine web app to select kiss and hug types, view explanations in a popup with an image, and generate a personalized Valentine wish from selected options.

## Features

- 10 kiss types with explanations
- 10 hug types with explanations
- Selection flow with popup preview (image + meaning)
- Wish generator that includes selected items, explanations, and images
- Copy generated wish text to clipboard
- Download generated wish as an image

## Run

Since this is a static web app, open `index.html` in your browser.

Quick way from terminal:

```bash
xdg-open index.html
```

Or use any simple static server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
